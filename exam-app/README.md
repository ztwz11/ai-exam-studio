# AI Exam Studio

현재 폴더의 상급 모의훈련 Q1~Q4와 CSV 자료를 사용하는 개인용 시험 화면입니다. Node.js 22 이상과 로그인된 Codex CLI가 필요합니다. 토큰 계산에는 고정 버전 `js-tiktoken@1.0.21`을 사용합니다. 현재 PC에는 설치되어 있으며, 새 PC에서는 이 폴더에서 `npm ci`를 먼저 실행합니다.

## 실행

상위 폴더의 `start-exam.cmd`를 더블클릭한 후 브라우저에서 <http://127.0.0.1:4318>을 엽니다. 또는 이 폴더에서 `npm start`를 실행합니다. 실행 창을 열어 둔 상태로 사용하고 Ctrl+C로 종료합니다.

CLI 로그인이 필요하면 로컬 터미널에서 `codex login`을 실행하세요. API 키를 입력할 필요 없이 CLI의 기존 ChatGPT 로그인을 사용합니다. CLI 사용량은 해당 계정 한도에 반영됩니다. 이 Codex 대화의 내용을 공유하거나 이어받지는 않습니다.

## 시험 기능

- 실전 모드 기본 90분, 문항당 AI 질문 3회. 시작 전에 변경 가능.
- 연습 모드에는 일시정지와 시간·질문 무제한(0) 설정.
- 서버의 종료 시각을 기준으로 계산하므로 새로고침해도 시간이 초기화되지 않음. 실전 모드에서는 브라우저나 서버를 닫아도 벽시계 시간이 흐름.
- 문항별 문제·CSV, AI 질문·답변, 최종 답안, 메모, 검토 표시, 작성 완료 표시.
- 답안 자동 저장, 시간 종료 시 자동 제출·수정 잠금, Markdown/JSON 내려받기.
- 문항별 사용 시간은 해당 문항을 선택한 시간이며 비활성 탭에서도 흐름. 사용자가 실제로 읽고 있었는지는 측정하지 않음.
- 실패·취소 요청은 질문 횟수에 포함하지 않음. AI 대기 시간은 시험 시간에 포함. 종료 이후 도착한 답변은 사용하지 않음.
- 첫 2분 AI 없이 읽기는 선택 사항이며 문항에 누적한 시간을 기준으로 적용.
- 최종 제출 또는 시간 종료 후 Astra High 자동 채점. 문항별 점수·부분점수·피드백·모범답안 확인 및 채점 포함 JSON 다운로드.

## 작은 문맥을 재현하는 방식

매 요청마다 `codex exec --ephemeral --ignore-user-config --sandbox read-only --json`으로 새 실행을 만듭니다. resume를 사용하지 않습니다. **새 시험의 기본값은 입력 4,096토큰, 표시 답변 1,024토큰**입니다. 입력은 128~32,768, 답변은 32~8,192 사이의 정수로 변경할 수 있습니다. 문제·선택한 CSV·최근 최대 2회 문답·현재 프롬프트·시험용 지침을 계산하며, 이전 대화를 전혀 전달하지 않을 수도 있습니다.

현재 질문과 첨부만으로 한도를 넘으면 전송을 거절합니다. 오래된 문답은 완전한 질문·답변 쌍 단위로 제외하고 UI에 포함·제외 수를 표시합니다. 현재 문항의 자료만 선택할 수 있고 정답 파일을 읽어 넣지 않습니다. 문맥 미리보기에 실제 자료 입력을 표시합니다.

기준 토크나이저는 **o200k_base**입니다. 입력 본문과 별도 시험용 지침을 각각 인코딩해 합산합니다. Codex 자체 시스템 프롬프트·관리 정책·도구 정의·메시지 포맷·추론 토큰은 로컬 입력 계산에 포함하지 않습니다. 따라서 이 값은 Codex가 보고하는 전체 사용량과 다르며, 실제 모델과 동일한 토크나이저라는 보장도 없습니다. 보고된 사용량은 `usage`로 별도 기록합니다.

**출력 제한은 생성이 완료된 답변을 화면에 제공하는 단계에서 적용합니다.** 한도를 넘으면 Unicode 경계를 보존해 잘라내고, 잘림 표시와 원본/표시 답변 토큰 수를 저장합니다. 잘린 원본 전체는 화면·후속 문맥에 넣지 않습니다. 이는 생성 중단이나 계정 사용량·비용 상한이 아닙니다. 공개 CLI 설정에서 확인되지 않은 `max_output_tokens` 옵션을 임의로 사용하지 않습니다.

기존에 저장된 글자 수 제한 시험은 그 입력 제한을 유지합니다. 토큰 기준으로 시작하려면 기존 시험을 제출한 뒤 새 시험을 만드세요. 실제 시험과 동일한 모델·난이도·성능을 보장하지 않습니다.

CLI 사용자 설정, 프로젝트 문서 자동 읽기, 호스트 스킬 검색, 셸·브라우저·앱·플러그인·메모리·멀티 에이전트·이미지 도구를 실행별 설정으로 비활성화합니다. 빈 임시 폴더를 작업 위치로 쓰고 읽기 전용 샌드박스를 유지합니다. CLI의 관리자 정책은 우회하지 않습니다. 응답 이벤트에서 명령·MCP·웹 검색·파일 변경이 관측되면 요청을 중단합니다. CLI 버전별 도구 구성 차이가 있어 이 장치를 보안 격리나 공식 감독 시스템으로 해석하지 마세요.

## 저장 및 연결

서버는 `127.0.0.1`에만 바인딩합니다. 임의 사이트의 요청을 막는 Origin·Host 검사와 요청 토큰 검사를 사용합니다. 사용자 프롬프트를 셸 명령 문자열로 조합하지 않고 CLI stdin으로 전달합니다. 브라우저에 CLI 인증 정보를 제공하지 않습니다.

기록은 `exam-app/.local/current.json`에 저장됩니다. 제출 후 새 시험을 시작하면 이전 기록을 시험 ID별 JSON으로 보존합니다. 이 폴더는 Git에서 제외됩니다. 개인용 단일 응시 화면이며 여러 탭에서 동시 편집하는 용도로 설계되지 않았습니다.

Codex가 표준 위치에 없으면 `CODEX_EXAM_BIN`에 CLI 실행 파일의 절대 경로를 설정할 수 있습니다. 모델을 지정하려면 `CODEX_EXAM_MODEL`에 계정에서 사용 가능한 모델 ID를 설정한 후 서버를 시작하세요. 미지정 시 사용자 config.toml과 별개인 CLI 기본 모델을 사용합니다. `PORT`로 포트를 바꿀 수 있습니다.

## Astra High로 문제 만들기

시험실 상단의 **문제 만들기 +** 또는 <http://127.0.0.1:4318/author>를 엽니다. 주제·난이도·권장 시간·배점·추가 요구를 지정한 뒤 **Astra High로 문제 생성**을 누릅니다.

- 생성 전용 모델은 `gpt-6-astra`, `model_reasoning_effort="high"`로 고정합니다. 시험 도우미의 `CODEX_EXAM_MODEL` 설정과 독립적이며, 모델 접근 오류가 나면 다른 모델로 대체하지 않고 오류를 표시합니다.
- Codex CLI의 기존 로그인과 계정 사용량을 사용합니다. 출력 JSON Schema를 지정하고, 문항 구조·길이·자료 파일명을 서버에서 검증합니다. 생성은 한 번에 1문항, 최대 8분이며 취소할 수 있습니다. 생성 중 새로고침해도 상태를 다시 표시합니다. 서버 재시작으로 중단된 생성은 실패 상태로 복구합니다.
- 문제 본문과 1~4개 CSV/MD/TXT 자료, 별도의 비공개 모범답안·해설·채점 기준을 생성합니다. PDF 바이너리는 생성하지 않으며, 시험실에서 별도 추가할 수 있습니다. 세부 기준의 배점 합계가 문항 배점과 맞는지 검사합니다. AI 출제와 채점은 연습용 참고 평가이며 내용의 정확성을 보증하지 않습니다.
- **문제 은행에 추가**를 누르면 `.local/problem-bank.json`에 저장합니다. 초안은 `.local/author-draft.json`에 남습니다. 중복 추가 요청은 같은 문항 ID를 반환합니다. 최대 50문항을 보관합니다.
- 새 시험 준비 화면에서 원하는 문제만 체크해 시험을 구성합니다. 총 문항 수·배점·권장 시간은 선택에 따라 바뀝니다. 진행 중인 시험은 생성·추가 후에도 기존 문항과 순서, 답안을 유지합니다.
- 생성과 시험 AI 질문, 하네스는 동시에 모델을 호출하지 않습니다. 시험 시간은 생성 중에도 계속 흐릅니다.

설정 근거: [공식 Codex 설정 레퍼런스](https://developers.openai.com/codex/config-reference). 설치된 CLI 모델 카탈로그에서도 Astra의 `high` 지원을 확인했습니다.

## 비공개 정답과 종료 후 자동 채점

- 출제 시 `answerKey`를 별도 구조로 생성해 `.local/private/answer-keys.json`에 보관합니다. 공개 문제 은행·초안에는 정답을 저장하지 않습니다. 문제 생성 미리보기에는 정답 준비 여부만 표시합니다.
- 시험·일시정지 중에는 정답, 해설, 세부 채점 기준을 화면·bootstrap·문항 목록·시험 AI 문맥·결과 조회 API로 전달하지 않습니다. 파일 다운로드 경로에서도 private 폴더를 제공하지 않습니다. 결과 조회는 현재 시험 ID와 제출 상태를 검사하며 새 시험이 시작되면 이전 시험의 정답 조회도 막습니다. 개인 연습용 앱의 화면/API 분리이며 PC 소유자가 로컬 파일을 직접 열어보는 것을 막는 보안 시스템은 아닙니다.
- 최종 제출 및 시간 종료 시 최종 답안과 자료를 고정하고 자동 채점을 예약합니다. 채팅·메모는 점수 산정에 사용하지 않습니다. 출제와 동일한 `gpt-6-astra` / `high`를 사용합니다. 다른 AI 요청이 진행 중이면 기다립니다.
- 모범답안·세부 기준과 제출 답안을 기준으로 항목별 점수, 제출 답안의 근거 인용, 감점 사유, 잘한 점과 개선점을 생성합니다. 서버가 항목 ID·점수 범위·0.5점 단위·실제 답안 인용을 검증하고 합계를 계산합니다. 응답 오류를 0점으로 처리하지 않으며, 실패한 문항만 재시도합니다.
- 새로 생성한 문제는 미작성 답안도 저장된 기준에 따라 0점 처리하고 모범답안을 제공합니다. 기존 문항에 기준이 없으면 작성한 답안을 참고하지 않고 문제·자료만으로 기준을 먼저 생성한 뒤 채점합니다. 기존 문항의 답안이 비어 있고 기준도 없으면 모델 호출 없이 0점을 기록하며 모범답안은 제공하지 않습니다.
- 결과는 `.local/private/grades/<시험 ID>.json`에 저장합니다. 서버 재시작 후 완료 결과는 유지됩니다. 진행 중이던 채점은 실패로 복구하고 재시도 시 이미 완료한 문항은 다시 호출하지 않습니다. 채점 도중에는 새 시험을 시작할 수 없습니다.
- 기본 자동 채점은 켜져 있습니다. 개발용 `EXAM_AUTO_GRADE=0`은 기존 HTTP 회귀검사에서 모델 호출을 방지하기 위한 설정입니다. 기본 시험에서는 변경할 필요가 없습니다. `test/grading-http-check.mjs`는 이 설정 없이 제출·시간 종료·정답 비공개를 검사합니다. `test/grading-live-prepare.mjs`는 실제 계정 사용량을 쓰는 별도 검증 자료 생성 스크립트입니다.

## PDF와 첨부 자료

- 시작 화면의 **시험 자료 목록**에서 문항을 고른 뒤 PDF, CSV, TXT, MD를 업로드합니다. 진행 중에는 **첨부 자료** 탭에서 현재 문항에 추가할 수 있습니다.
- 업로드는 파일당 10MB, PDF 100페이지, 추출 텍스트 300,000자, 문항당 20개로 제한됩니다. TXT/CSV/MD는 UTF-8입니다. 원본과 추출 텍스트는 `.local/materials/`와 `.local/materials.json`에 저장됩니다.
- 업로드 자료는 자동으로 AI에 전달되지 않습니다. 오른쪽 **AI에 함께 전달**에서 선택합니다. 파일별 토큰, 선택 합계, 잔여 한도를 확인할 수 있습니다. PDF 원본을 다운로드하고 AI가 읽을 추출 텍스트를 먼저 확인하세요.
- 새 시험의 **첨부 자료 한도** 기본값은 3,072토큰입니다. 0은 첨부 불가이며, 전체 입력 한도를 넘게 설정할 수 없습니다. 파일명 표기를 포함한 파일별 `o200k_base` 토큰 합계로 계산합니다. 파일 사이 구분자는 전체 입력 예산에 포함됩니다.
- 첨부 한도와 전체 입력 한도(기본 4,096토큰)를 모두 검사합니다. 문제 원문·프롬프트·지침·최근 대화는 전체 입력 예산을 사용합니다. 첨부 초과는 자동 요약하거나 자르지 않고 요청을 차단합니다. 진행 중 시험은 기존 설정을 유지하며, 첨부 한도 값이 없는 기록에는 3,072토큰(입력 한도가 더 작으면 그 값)을 적용합니다.
- PDF는 페이지 번호가 붙은 **텍스트**로 전달합니다. 그림·차트·스캔 이미지를 해석하거나 OCR하지 않습니다. 텍스트 없는 PDF는 거부하며, 일부 빈 페이지는 경고합니다. 표·수식의 추출 순서는 원본과 대조해야 합니다. 암호화 PDF는 지원하지 않습니다.
- 이 수치는 연습용 설정이며 프로그래머스나 SK하이닉스의 공식 시험 한도를 의미하지 않습니다.

### 테스트 하네스

서버 실행 후 <http://127.0.0.1:4318/harness> 또는 시험 시작 화면의 **테스트 하네스 열기**를 선택합니다. 사례 JSON, 토큰 한도, 반복 횟수를 편집하고 실행할 수 있습니다. 진행 중인 시험과 하네스는 동시에 실행하지 않습니다.

- **모의 실행:** `mockResponse`로 입력 차단, 답변 제한, 기대값 비교, 문맥 포함 규칙을 점검합니다. Codex를 호출하지 않으며 모델 성능 검증이 아닙니다.
- **실제 실행:** 같은 시험용 실행 경로로 Codex CLI를 호출합니다. 계정 사용량이 발생합니다. `expect`와 `mockResponse`는 모델에 전달하지 않습니다.
- 기본 사례: 계산, 자료 근거, 입력 초과 차단, 긴 출력 제한, 최근 문답 2회. 긴 출력·대화 개수 사례는 모의 실행 전용입니다.
- 최대 10사례 × 3회. 실패·취소·건너뜀, 응답 시간, 입력 토큰, 원본/표시 답변 토큰, CLI의 실제 사용량을 기록합니다.
- 결과는 `.local/harness/harness-<UUID>.json`과 `.md`에 저장됩니다. 웹 화면에서도 JSON을 내려받을 수 있습니다. 서버 재시작 후 이전 결과는 파일에서 확인합니다.
- CLI 하네스는 실패·취소 시 종료 코드 1을 반환합니다. 동일한 모델 조건으로 비교하려면 서버/하네스 실행 전에 `CODEX_EXAM_MODEL`을 고정하세요. 기본 모델 미지정 상태는 결과에 표시합니다.

이 폴더에서 실행하는 명령:

```powershell
npm run harness
npm run harness -- --repeat 2 --input-tokens 2048 --output-tokens 512
npm run harness:live
npm run harness:live -- --cases harness/cases.example.json --repeat 2
```

상위 폴더의 `run-harness.cmd`를 더블클릭하면 모의 하네스를 실행합니다. 사용자 정의 사례 예시는 `harness/cases.example.json`을 참고하세요. `expect.equals`, `contains`, `notContains`, `json`, `blocked`, `truncated`, `includedTurns`, `droppedTurns`를 지원합니다. 정확한 문자열 비교와 JSON 파싱은 잘린 뒤 실제 제공되는 답변을 대상으로 합니다. 코드나 정규식을 실행하는 검증 규칙은 지원하지 않습니다.

### 자동 회귀검사

`npm test` 또는 `node --test test/*.test.mjs`로 시간 종료, 무제한 설정, 문맥 초과, 첨부 선택, 대화 누락·질문 횟수의 핵심 규칙을 확인합니다.

`npm run test:integration`은 임시 서버·기록으로 저장, 문항 이동, 문맥 검증, 제출 잠금과 일시정지를 확인합니다. `node test/integration-check.mjs --live`는 실제 Codex 질문 1회를 추가로 사용해 답변과 질문 한도를 검증합니다. `npm run test:cli`는 간단한 계산 질문으로 CLI 연결을 진단합니다.

`npm run check`는 단위 검사와 HTTP 통합 검사를 함께 실행합니다. 기본 검사에는 실제 모델 호출이 없습니다. JSON 이벤트 분할, UTF-8, 도구 사용 차단, CLI 시간 초과·취소, 토큰 경계, 기대 답 누출 방지, 하네스 실패 보고도 검사합니다.

참고: [공식 Codex CLI exec 문서](https://learn.chatgpt.com/docs/developer-commands#codex-exec), [공식 설정 레퍼런스](https://developers.openai.com/codex/config-reference).
# 시험 전체 초기화

시험 화면의 **타이머 초기화**를 누른 뒤 **전체 초기화 후 재시작**을 선택하면 현재 시험의 모든 문항을 처음부터 다시 풉니다. 같은 문항·자료·설정을 유지하고, 제한 시간과 문항별 풀이 시간, 답안, 메모, 프롬프트 초안, AI 대화·질문 횟수, 완료·검토 표시를 초기화합니다. 첨부 선택은 시작 시 기본값으로 돌아갑니다. 새 응시 ID를 발급하고 첫 문항부터 즉시 시작하며, 일시정지 상태도 해제됩니다. 종료한 시험에서도 사용할 수 있습니다.

진행 중인 AI 요청이나 자동 채점이 있으면 완료 또는 취소 후 초기화합니다. 이전 응시 기록은 `.local/<이전 응시 ID>.json`에 복구용으로 보관하며, 이전 채점 결과는 새 시험 API에서 조회할 수 없습니다. 이미 본 정답에 대한 기억까지 초기화되지는 않습니다.

공개 저장소에는 소스와 가상 예제 자료만 포함합니다. `.local/`의 생성 문제·비공개 정답·업로드 자료·시험 기록, 인증 파일, 의존성 설치 폴더는 Git에서 제외합니다.
