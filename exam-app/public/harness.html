실행 설정

토큰 수의 기준

o200k_base로 계산한 자료·대화·지침의 토큰 수입니다. Codex 내부 문맥은 제외됩니다. 출력은 받은 답변을 제한하며, 생성 토큰이나 비용의 상한은 아닙니다.

모의 실행은 mockResponse를 사용해 제한·검증 동작을 확인합니다. 모델 성능을 평가하지 않습니다. 실제 실행에는 기대 답과 mockResponse를 전달하지 않습니다.

테스트 사례

사례 작성 방법

id, prompt는 필수입니다. material은 제공 자료, expect.equals는 정확한 기대 답, contains/notContains는 포함/제외할 문구 배열입니다. json, blocked, truncated는 true/false, includedTurns/droppedTurns는 문답 수입니다. 입력·답변 한도는 사례별로 덮어쓸 수 있습니다. modes가 ["mock"]인 사례는 실제 실행에서 제외됩니다.
