## 구현된 프리셋

이름은 **프로그래머스형 제한 연습**이며, “2차 공식 환경”이라고 표시하지 않는다. 2차 생성 문항에서 시험 준비로 이동하면 이 프리셋을 불러온다. 시간은 생성 문항의 연습 시간으로 설정한다.

- 가이드 색인본 기반: 프롬프트 1,000자, 첨부 20,000토큰, 최근 최대 10문답 쌍, 첨부 선택 매번 초기화, 30초 전송 간격, 문제·자료 복사 제한.
- 1차 후기 참고값: 전체 질문80회, 첨부5개. 모두 수정 가능하며 2차 공식 수치로 표시하지 않는다.
- 앱 자체 연습값: 입력32,768토큰, 프롬프트4,096토큰, 표시 답변2,048토큰, 파일10MB, PDF100페이지. PDF는 추출 텍스트만 사용하며 이미지/OCR은 지원하지 않는다.
- 모델은 실제 CLI 호출에 명시적으로 전달한다. 기본 Astra High, Sol/Luna 및 Low/Medium/High 선택. 설치된 CLI 모델 카탈로그에서 모델명과 수준을 확인했다. GPT-5.2는 현재 확인한 로컬 카탈로그에 없으므로 선택 가능한 척하거나 다른 모델로 가장하지 않는다. 실제 시험과의 성능 동등성은 검증하지 않았다.
- 시험 중 새 파일 업로드는 프리셋에서 끈다. 시작 전 등록은 가능하며 선택 파일의 수·크기·페이지·토큰을 요청 시 다시 검사한다.

## 강제 적용과 재현 한계

새 시험의 설정은 서버 세션에 저장한다. 저장/질문 요청에 설정을 섞어 보내도 현재 시험 설정이 바뀌지 않는다. 초과 요청은 CLI 실행 전 차단한다. 전체 질문 풀·30초 전송 간격은 문항 이동과 새로고침에도 유지한다. 취소·실패는 질문 횟수에 포함하지 않지만 전송 대기는 유지한다. 초기화하면 새 시험 ID와 함께 기록·쿨다운도 초기화한다. 기존 시험 기록은 자동 변환하지 않는다.

토큰 계수는 o200k_base로 앱이 보내는 지침·문제·선택 자료·최근 문답·프롬프트를 계산한다. 최신 입력을 자르지 않고 오래된 문답 쌍부터 제외한다. 이전 파일의 본문은 재전송하지 않지만, 그 내용을 언급한 이전 AI 답변은 최근 문답에 남을 수 있다. 첨부20,000토큰은 전체 입력 한도와 별개로 검사하며 전체 입력 안에 포함된다.

[OpenAI Codex 설정 문서](https://developers.openai.com/codex/config-reference)의 모델/추론 수준 설정을 사용한다. 출력 표시 한도는 원본 응답을 받은 뒤 자르는 제한이며 실제 생성/추론 토큰이나 비용의 하드캡이 아니다. CLI 내부 시스템 문맥·모델 업데이트·추론 자원·토크나이저 차이까지 같게 만들 수는 없다. 모델이 없거나 호출에 실패하면 오류를 보여 주며 다른 모델로 자동 대체하지 않는다.

검색·파일 탐색·코드 실행·외부 앱은 시험 AI에서 비활성화한다. 이 앱의 텍스트 제출·참고 채점은 Cofa의 실제 IDE/실행 검증·후속 면접·감독 환경을 재현하지 않는다. 복사 제한은 화면 사용 습관을 연습하기 위한 기능이며 브라우저 개발자 도구까지 막는 감독 시스템이 아니다. 생성된 정답과 채점 기준은 이전과 동일하게 제출 전 비공개다.
