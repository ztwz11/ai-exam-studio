# AI Exam Studio

Codex CLI를 이용한 개인용 AI 활용 역량 모의시험 앱입니다. 문제·첨부 자료·프롬프트 입력·최종 답안·타이머를 한 화면에서 제공하며, Astra High 문제 생성과 비공개 정답·채점 기준, 종료 후 자동 채점을 지원합니다. **타이머 초기화**는 현재 시험의 모든 풀이 기록도 함께 초기화합니다.

Node.js 22 이상과 로그인된 Codex CLI가 필요합니다. Windows에서는 `start-exam.cmd`를 실행하세요. 다른 환경에서는 `cd exam-app`, `npm ci`, `npm start` 순서로 실행합니다. 검증은 `exam-app`에서 `npm run check`로 실행하며 기본 검증에는 실제 AI 호출이 없습니다. 모델 사용 가능 여부는 로그인한 계정에 따라 다릅니다.

생성 문제·정답·업로드 자료·시험 기록은 로컬에만 저장되며 이 저장소에 포함되지 않습니다. 자세한 설정과 제한은 [앱 안내](exam-app/README.md)를 참고하세요.

## 무엇을 위한 자료인가

공개 체험문제 다음 단계에서, 여러 자료를 함께 읽고 수치를 검산하며 AI가 작성한 초안의 잘못된 판단을 수정하는 연습이다. 실제 SK하이닉스·프로그래머스의 기출, 유출, 복원 또는 난이도 보정 모의고사가 아니다. 모든 회사·정책·운영 데이터·AI 초안은 이 연습을 위해 만든 가상 자료다. 실제 출제 범위와 합격 점수는 알 수 없다.

프로그래머스의 공식 설명에서 참고한 것은 ‘결과와 AI 활용 과정을 함께 평가한다’는 방향뿐이다. 아래 4문항, 90분, 질문 3회, 배점 및 분량은 제작자가 정한 훈련 조건이다. 계산기·코드 사용 허용도 이 연습에만 해당한다. 실제 응시 규칙은 개별 시험 안내를 따른다.

## 진행

| 문항 | 과제 | 권장 시간 | 배점 |
|---|---|---:|---:|
| 1 | 서로 다른 평가 자료로 AI 도입 여부 결정 | 25분 | 30점 |
| 2 | 여러 문서를 근거로 실행 계획 작성 | 20분 | 25점 |
| 3 | 운영 지표 집계 코드 검토·수정 | 25분 | 25점 |
| 4 | 품질·정보 취급·자원 제약을 만족하는 처리 배분 | 20분 | 20점 |

각 문항은 독립적이다. 1번이 틀려도 나머지 문제 풀이에 영향을 주지 않는다. 문제에 필요한 규칙·단위·용어는 제공 자료 안에 있다. 반도체 전공지식, 라이브러리 암기, 웹 검색이 필요하지 않다. ‘실제 세상에서는 다를 수 있다’는 이유로 주어진 가정을 바꾸지 않는다. 불명확한 부분을 발견하면 자신이 사용한 가정을 명시한다.

## 두 가지 풀이 모드

첫 진단은 다음 조건을 권한다.

- 문항마다 처음 2분은 AI 없이 읽고, 요구 결과와 반드시 지켜야 할 조건을 메모한다.
- 이후 문항당 AI 질문 최대 3회. 첨부 분석도 한 번의 질문에 포함한다. 필요 없으면 억지로 질문을 채우지 않는다.
- 로컬 계산기, Python·SQL·스프레드시트는 허용한다. 개인정보나 운영 자격은 사용하지 않는다. 외부 웹 검색은 하지 않는다.
- 마지막 2분은 AI의 ‘정답’ 표시를 보지 말고 직접 답안 요구사항과 계산을 대조한다.
- 작성한 프롬프트와 어떤 답을 받아들였거나 수정했는지를 `templates/answer_sheet.md`에 짧게 기록한다. 긴 사고과정 공개는 필요하지 않다. 재현 가능한 계산·근거·수정 요지만 남긴다.

90분과 질문 횟수는 시스템이 강제하지 않는다. 응시자가 직접 기록한다. 빠르게 마친 뒤 시간이 남으면 검토하고, 검토 종료 시간까지 기록한다.

두 번째로 풀 때에는 같은 정답을 외워 반복하지 말고 조건을 바꾼 새 문제를 사용한다. 이 자료의 고득점은 이 문항을 해결했다는 의미이지 실전 합격 가능성이나 상위 백분위를 뜻하지 않는다.

## 파일 사용 방법

- `tasks/Q1.md` ~ `tasks/Q4.md`: 문제와 원문 근거.
- `data/`: 해당 문제의 CSV 자료. Q1·Q4의 표는 문제에도 같은 값으로 들어 있다. Q3는 CSV를 함께 읽는다.
- `templates/answer_sheet.md`: 제출 답안과 짧은 AI 활용 기록.
- `templates/practice_assistant_prompt.md`: 별도 대화에서 연습용 AI를 사용할 때의 선택적 설정.
- `reference/sources.md`: 실제 공개 평가 서비스에 관한 참고자료. 가상 문제의 정답 근거는 아니다.

정답·해설·검증 프로그램은 이 ZIP에 포함하지 않았다. 문제 파일만 AI에 첨부하고 정답 파일까지 같이 넣지 않는다. 이후 자신의 답안과 대조할 때 별도 해설을 사용한다.

## 채점 원칙

계산과 제약조건 적용, 결론의 근거를 평가한다. 키워드를 길게 나열하거나 ‘사람 검토가 필요하다’로 모든 결정을 미루는 것은 높은 점수의 근거가 아니다. 허용되는 일은 처리하고, 확인되지 않은 부분만 보류하는 판단을 구분한다. 논리적으로 같은 대안·다른 코드 언어도 인정한다.

제공 문서와 수치에서 나오지 않는 성능·정책·권한을 만들어내면 해당 항목은 점수를 주지 않는다. 최종 수치만 맞고 계산 기준이 없으면 부분 점수다. 답안 기록에 AI가 없었다고 해서 임의로 대화를 꾸며 작성하지 않는다.
